# Pilot Findings (exploratory)

**Status:** Exploratory — computed on 179 scored predictions collected while the pipeline config
was still changing (model Llama→gpt-oss, single→multi-agent, prompt edits). These numbers **motivate**
the frozen confirmatory study; they do not establish the headline claim on their own.

Generated by `baseline.py` and `analysis/mechanism.py`.

---

## 1. Accuracy vs naive baselines (n=179)

| Strategy | Accuracy |
|---|---|
| Always UP | **52.0%** (best baseline) |
| Coin flip (up/down) | 48.2% |
| Always DOWN | 44.7% |
| Always NEUTRAL | 43.6% |
| **EP Engine (actual)** | **41.9%** |

The full pipeline underperforms every naive baseline, including always guessing UP. (Caveat: the
"always UP" edge is partly a bull-market artifact of this window — the honest claim is *"no edge over
naive baselines,"* not "always-UP is a good strategy.")

## 2. Directional calls vs a coin flip (the core test)

- n = 77 directional (UP/DOWN) calls, 31 correct → **40.3%**
- 95% bootstrap CI: **29.9%–50.6%**
- Two-sided binomial vs 50%: **p = 0.11 (not significant)**

**Key honesty point:** the point estimate is below chance, but the CI still spans 50% — with only 77
directional calls we **cannot yet claim "worse than chance."** This is the single strongest argument
for the frozen run: ~200 directional calls would narrow this CI enough to settle it.

## 3. Failure mechanism (H3) — the interesting part

- **Chase rate: 69%** — the pipeline predicts continuation of the move that *already happened* in the
  prior 3 days, in 69% of directional calls. It chases momentum.
- **Chasing doesn't pay:** calls that chased prior momentum were 40% correct; calls that fought it were
  42%. Both below chance.
- **Prior moves reverse 54% of the time** across all assets — mildly mean-reverting.

Coherent story: the pipeline reads news that reflects a move already priced in, bets the move
continues, and it reverses more often than not. The reversal signal is only mild (54%) on this sample,
so this is a hypothesis to sharpen in the frozen run, not a settled result.

---

## What this means for the study

The pilot points consistently toward a null/negative result with a plausible mechanism, but is
**underpowered** to prove it. Proceed to the frozen, pre-registered prospective run (~500 predictions,
gate-on and gate-off arms) as designed in the plan.
